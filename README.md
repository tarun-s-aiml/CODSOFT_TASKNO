# CODSOFT Python Programming Internship

## Overview

This repository contains the Python programming tasks completed as part of my CodSoft Python Programming Internship.

The projects demonstrate fundamental Python programming concepts including functions, loops, conditional statements, data structures, randomization, user input handling, and basic application development.

## Tasks Completed

### Task 1 - To-Do List

A command-line To-Do List application that allows users to:

- Add tasks
- View tasks
- Delete tasks
- Exit the application

File:
`Task1_ToDo_List/todo_list.py`

---

### Task 2 - Calculator

A command-line calculator that performs:

- Addition
- Subtraction
- Multiplication
- Division

The program also handles invalid input and division by zero.

File:
`Task2_Calculator/calculator.py`

---

### Task 3 - Password Generator

A password generation program that creates random passwords based on the length specified by the user.

The generated password contains a combination of:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

File:
`Task3_Password_Generator/password_generator.py`

---

### Task 4 - Rock-Paper-Scissors Game

A command-line Rock-Paper-Scissors game where the user plays against the computer.

Features include:

- Random computer selection
- Winner determination
- Score tracking
- Multiple rounds

File:
`Task4_Rock_Paper_Scissors/rock_paper_scissors.py`

---

### Task 5 - Contact Book

A command-line Contact Book application that allows users to manage contact information.

Features include:

- Add contact
- View contacts
- Search contact
- Update contact
- Delete contact

Each contact contains:

- Name
- Phone number
- Email address

File:
`Task5_Contact_Book/contact_book.py`
